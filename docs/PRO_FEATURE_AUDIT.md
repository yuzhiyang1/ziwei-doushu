## 证据与边界

- `npm test`包含引擎、时序、分析、输入、学校、存储、数据集Worker、天空、双盘、研读等23组脚本。
- `npm run test:ui`在GitHub Actions开启Chromium sandbox，合成出生/JSONL与mock模型；不发送真实资料到模型。
- 研读存储按合并后全库2MB/5000条原子验证，避免正常保存后无法导出；取消确认不写、失败保留旧库。
- 命理属于传统文化而非科学预测。算术盘面事实、来源摘编、自研意象与模型生成解释分别标识，不能混用。
- PR保持draft，未合并、未部署。最终提交/CI证据在PR正文，避免把旧版本测试结果冒充最新验收。
