# 阅读优先的命盘工作区

## 真实问题复现（2026-10-30）

在 a52d35a 对应部署上，用合成1990-05-09辰时实际起盘：13主题按钮存在，但默认总览主要是叠宫列表、无流曜提示和配置串；没有说明这张盘的紫微/破军等组合意味着怎样的传统观察角度。用户“没有命盘分析”的反馈成立，旧测试仅验证节点和技术字段，不能视作解读体验验收。

另发现 ChartBoard 等使用的 `--t-bg/--t-border/--t-text` 等变量没有定义，宫格边框和控件层级失效。不是浏览器资源加载失败。

## 本轮修复

- 依据官网公开前端可观察布局独立实现：明亮无衬线、细分隔、桌面左命盘右分析，手机分析优先并可切命盘/AI。未复制私有前端业务源码或突破登录。
- 本地可读分析自动生成，不要求Key、公开数据导入或先点“生成AI”。每主题含摘要、可发挥特点、需留意张力与日常建议；总览实际结合命/财/官/夫妻及身宫。
- 14主星各有自编解释/张力/应对规则；空宫借对宫明确标示，不冒称本宫有星。命理内容仍是传统象征而非人格或事件事实。
- 技术依据保留，但默认折叠；高级流派/匹配/数据工具收纳。AI独立标签，明确可选。
- 定义完整主题token，修正宫格字号、边界、键盘选择。新用户默认浅色，已有主题偏好保留。
- 报告先列可读解释，后附计算依据；打印宫名按钮专门保留。PNG实际导出纳入截图证据。

## 验收改变

- 起盘后不预先滚动就保存桌面/手机首屏；摘要必须在可视区域且真实绘制。
- 六层×13主题均有可读摘要/特点/张力/建议；比较不同命盘，不能只验证名称和主题数量。
- 单元验证不同盘剥离星名后仍存在实质差异；108盘总览长度160–288字。
- 390px移动主路径、350/500px图盘、键盘选宫、隐藏面板展开、无需Key的本地分析及原有存储/导出/AI回归。
- 最终CI和截图以PR所列具体提交为准。真实模型仍未配置；自带模型测试使用mock。
