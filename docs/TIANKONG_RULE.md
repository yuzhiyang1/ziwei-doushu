# 天空「顺加生时」：独立规则与来源边界

这是按用户要求、依据公开规则说明编写的可选算法，不是官网服务端代码复原，也不声称唯一正统或预测有效。默认仍为原引擎的年支天空。

## 可复核推导

支序固定为子0、丑1、寅2、卯3、辰4、巳5、午6、未7、申8、酉9、戌10、亥11。

1. [《紫微斗數安星法》公开文章](https://m.8zml.com/tcn/h-nd-131.html)（2016-10-11）描述年支天空：子年起丑，依次顺行到亥年起子，再从此起点顺加生时。同文火铃起时例采用起宫计子，午时前进6宫。
2. [DestinyNet 2005年讨论](https://destiny.to/ubbthreads/topic/46974)转引归于「紫微杨」的观点，给出甲子年午时天空落未的具体例子。
3. 因此起点为年支后一宫，子时零步，出生时支每增加一位顺行一宫；推导为：

```text
年支天空 = (年支索引 + 1) mod 12
顺加生时 = (年支索引 + 1 + 出生时支索引) mod 12
```

这不是把「子时」当1再加一次。例：子年子时→丑；子年午时→未；子年亥时→子；亥年子时→子；亥年亥时→亥。规则没有男女/阴阳逆排分支。

## 同名异星必须区分

[iztro 官方安星诀](https://docs.iztro.com/learn/setup)分别列年支天空与时系空劫。古书的「天空地劫诀」可能把现代地空称为天空，因此不能套到本次规则：

| 引擎星名 | 依据 | 本次是否改变 |
| --- | --- | --- |
| 天空 | 年支后一宫；备选再顺加出生时支 | 只改变这一颗 |
| 地空 | 亥起子时逆行 | 不改 |
| 地劫 | 亥起子时顺行 | 不改 |
| 截空、副截 | 生年干表与既有选择 | 不改 |
| 旬空、副旬 | 年干支所在旬 | 不改 |

## 实现口径

- 使用引擎已算出的农历年支，不拿公历年份取模；春节换年沿用引擎。
- 使用真太阳时/晚子时处理后的出生时支；不重复校时，不新增历法规则。
- 只对新生成盘移动天空并按所选亮度表重算其亮度；默认路径不动原盘。
- 配置 `tiankong: 'year-hour'` 随档案/备份保存，进入报告与用户授权的模型上下文；省略或 `year` 保持旧备份兼容。
- 时辰未知仍是子时示例，不能以假定子时的结果当已知出生时辰。
- 年度公开数据匹配继续使用默认年支天空口径；公开原文不因本选项改写。
